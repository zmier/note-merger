# Note Merger v1.4.0 版本说明

发布时间：2026-03-24

## 本次更新

`v1.4.0` 新增了 CriticMarkup 可视化能力，让 Obsidian 可以更自然地承接论文审读与返修场景。

## 新增功能

- 支持 CriticMarkup 五种基础语法：
  - Addition
  - Deletion
  - Substitution
  - Highlight
  - Comment
- 阅读视图下自动将原始语法渲染为语义化彩色标记
- Live Preview 下将标记折叠为可视化标签
- 点击可视化标签后可回到原始语法继续编辑

## 视觉方案

- 新增：柔和绿色
- 删除：柔和红色
- 替换：红绿并置
- 高亮：低饱和黄色
- 批注：低饱和紫色

整体风格采用偏学术、低饱和、长时间阅读友好的配色策略。
